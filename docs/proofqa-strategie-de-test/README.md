# Stratégie de test · ProofQA v1

Stratégie de test conçue pour la première version de **ProofQA**, une plateforme SaaS de Quality Assurance éditée par Titimbē Forge, en suivant la méthode **ISTQB Foundation v4**.

## La démarche

1. Décrire le produit, ses utilisateurs et leur problème
2. Délimiter et prioriser le périmètre (MoSCoW)
3. Formuler les exigences en user stories
4. Analyser et coter les risques (probabilité × impact)
5. Définir l'approche : niveaux, techniques, outils
6. Fixer les critères d'entrée, de fin et de lancement
7. Organiser le travail : environnements, intégration continue, anomalies
8. Rédiger les critères d'acceptation en Gherkin
9. Tracer les actions en attente
